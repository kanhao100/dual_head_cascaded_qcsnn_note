## 全测试集误分类浏览器

入口：`qcsnn_error_browser.html`。用 Edge 或 Chrome 打开即可离线使用；页面内嵌
20,161 个心拍的预处理输入、RR、整数输入字和保存的 C++ `topFunction` 输出。
使用浏览器原生 gzip 解压，无网络依赖。

2. 点击「全部错分类」，或筛选一级漏检、正常误入二级、二级错分类、二级纠正，以及记录编号。

路由统计包含最终判对的心拍，不能直接作为最终错分类数量。这里的数字由保存文件
重算，不复用 README 中四舍五入后的论文汇总。

新页面约 19.5 MiB，包含完整测试集。两页需放在同一目录才能跳转到逐层回放；

## 查看一层的真实整数

1. 在「信号流动画」选择心拍，播放、单步或拖动到所需位置。
2. 点击任意模块方框，或在「查看块」选择模块并点击「打开真实数据」。
3. 查看器默认打开该块**当前实际显示**的时间步。阶段 2 中，上方主干保留的是阶段 1 的 t=9；四分类头使用相应 t 的缓存。
4. 可切换 t=0…9，调整格子尺寸，滚动完整矩阵。通道和位置从 0 开始；鼠标指向格子，或用数字输入和方向键选择整数。
5. 下方显示整数的计算来源。卷积和 FC 可展开全部乘加项；BN 显示五成双；LIF 显示 bank、t−2 膜电位、Q12 舍入和延迟复位；QI 后的 RR 旁路与前 480 个数分别解释和核对。
6. Esc 关闭查看器，焦点返回打开它的控件。

灰色空图在当前动画尚未产生结果时不代表全 0。门控判为正常的心拍不执行四分类头，也不会生成该头的张量。显式选择时间步是在查看完整的功能模型结果，不是把动画提前执行。

页面数据来自作者预处理的真实 MIT-BIH 测试心拍和导出权重，经 JavaScript 整数模型重算，并与 CPU 上 C++ 的输出核对。播放顺序是函数层面的信号流解读；没有声称 FPGA 实测波形或 RTL 周期级数值一致。

## LIF 水桶动画

第 06 节「LIF 神经元动画」先用“漏水的桶”讲：两只桶 V0/V1 并排，偶数步用 V0、奇数步用 V1；每一步分五个小阶段播放（读出、漏水、灌入、延迟复位、判定），水位、阈值线、冲出的脉冲和右侧算式同步变化，底部时间轴把同一只桶的前后两次用法连起来，表现“第 t 步接第 t−2 步”。数字全部来自 `neuron()`，它与模型张量逐个核对（`Tr.ok`）。原来的整数数据通路、电位曲线收进“展开”里。源码在 `anim_c.js` 的 `bucket animation` 一段，一次性补丁脚本 `_patch_lif.py` 留作记录。

## 内部调度图

硬件地图的「内部调度」页签不再是折叠的文字列表：每个内部模块画成一张调度图。列是报告里的状态 / 流水阶段，行是功能泳道（LIF 用四条专用泳道，其余模块按绑定分存储、DSP、LUT 逻辑、连线、控制寄存器），色块是该级调度的一类操作，颜色表示绑定到什么硬件，悬停看算子、位宽、C++ 行号；点击一列（或用左右方向键）在下方看这一级的完整操作表。图下方的“流水叠放”表按 II 和深度画出每一拍每一级里是哪个迭代，播放时能看到各级逐级填满。原来的文字明细收在一个折叠项里。补丁脚本 `_patch_sched.py` 留作记录。

## 更直观的四处改动

- 卷积 1：输入和输出画成波形折线，3 点窗口落在波形上，滤波器权重、窗口、乘积画成柱状图，16 个滤波器画成小图廊，点一个就切换通道。卷积 2、3 仍用热图加数表。
- 全连接：输入、选中输出的权重、逐拍乘积三行对齐，下面是累加值随广播个数增长的折线（二分类和 4 分类输出是几条线在赛跑，128 个输出时高亮选中的那条）。
- BN 与取整：加了数轴，精确商落在哪两个整数之间、“一半”在哪、五成双和加半再右移各取哪个，一眼可见；“五成双演示”里同样有。
- 硬件地图「资源与存储」：HLS 预估与布线后占整块 xc7z020 的比例画成条，每块 RAM 画成一个小方块。

补丁脚本 `_patch_visual.py`、`_patch_res.py` 留作记录。

## 微架构页：`qcsnn_micro_arch.html`

面向懂 FPGA 的读者，讲 LIF 神经元和卷积引擎在硬件上怎么实现（DSP48、BRAM、LUT、FIFO、握手）。所有源文件在 `micro/`，用 `python micro/build_micro.py` 重新生成。

- 证据来源三类：HLS 生成的 Verilog 与报告（由 `extract_micro.py` 解析成 `micro_data.json`）；xsim 对生成模块的 RTL 仿真；已验证的整数模型导出的预期值。
- 仿真：`gen_tb_lif.py` / `gen_tb_conv.py` 生成测试平台，`run_everything.py` 一键跑完并比较（`compare_*.js`）。结果在 `micro/sim/`：LIF 六个模块 40 个用例 + 随机 FIFO 停顿，卷积 2、3 共 54 次运行（含输入缓冲预载垃圾、随机停顿），模型逐值比较 0 差异。
- 范围：模块级仿真，FIFO 与 LIF 的 V 存储为行为模型；没有整机仿真、时序或布线后仿真；布线后资源只有层级汇总。
- 页面内容：`micro_body.html`（结构与文字）、`micro_lif.js`、`micro_conv.js`、`micro_verify.js`（各节的图与表）、`micro_core.js`（公共工具）。
